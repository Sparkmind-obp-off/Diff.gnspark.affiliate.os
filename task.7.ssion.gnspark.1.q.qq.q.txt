6. AUTHORIZATION DECISION MODEL

  permission,

resource belongs to the same workspace when a resource is involved

Any failed condition MUST result in denial.

7. TENANT ISOLATION

Tenant isolation is mandatory.

A user from Workspace A MUST NOT access Workspace B resources merely because:

they know the resource ID
they know another workspace ID
they manipulate request parameters
they possess a valid authenticated account
they possess a valid role in another workspace

Authorization must never rely solely on:

accountId

when the resource is tenant-scoped.

Tenant-scoped resources must be evaluated using:

workspaceId

plus the authenticated account/membership context.
